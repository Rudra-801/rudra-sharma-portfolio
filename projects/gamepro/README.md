# NEXARC

Premium browser arcade redesign of the original GamePro project.

## Start
Open `index.html` with VS Code Live Server.

## Structure
- `assets/css/app.css` — authoritative platform design system
- `assets/js/app.js` — navigation + game registry
- `games/` — new isolated games
- `legacy/` — original games preserved for compatibility

New games: 2048 Neon, Flappy Nova, Reaction Rush, Aim Lab Mini. Original eight games remain available.
