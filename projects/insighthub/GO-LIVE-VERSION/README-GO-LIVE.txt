INSIGHTHUB - GO LIVE VERSION

1. Open the GO-LIVE-VERSION folder in VS Code.
2. Install the Live Server extension by Ritwick Dey.
3. Right-click index.html.
4. Select "Open with Live Server".

The site opens immediately and works without npm, MongoDB or terminal commands.

WORKING FEATURES
- Responsive home page
- Article listing
- Search, category filter, sorting and pagination
- SEO-style article routes using URL hashes
- View counter
- User login demonstration
- Admin role demonstration
- Admin dashboard
- Create, edit, publish, draft and delete articles
- Browser localStorage persistence
