Privacy Policy

Last updated: 1 September 2026

This policy describes the current NEXZO project implementation. Features that require a separately deployed backend or external provider operate only when that service is configured.

Data we process

  • Account data such as display name, email, verification state and profile photo URL.
  • Study data such as tasks, progress, focus sessions, XP, rewards, quiz results and saved resources.
  • Community data such as posts, groups, memberships and messages.
  • Assistant prompts, chat history and uploaded content when those features are used.
  • Limited local diagnostic records when diagnostics are enabled.

Where data is stored

Data may be stored in Firebase Authentication, Firestore, browser local storage or IndexedDB. Uploaded files require a configured storage service. Assistant requests may be sent to the configured backend and model provider.

Browser storage and consent

NEXZO uses essential browser storage for authentication state, security and core preferences. Optional analytics and personalization choices are presented through the Consent Center and can be changed later in Settings. Browser notification permission is requested separately only after the user chooses to enable notifications.

Controls

Users can change privacy, consent, personalization and notification preferences in Settings. Disabling personalization should prevent stored learning context from being included in new assistant requests.

Retention and deletion

Local data remains until cleared by the user or browser. Cloud data remains until deleted through supported account controls or an administrator-assisted deletion process.

Security

NEXZO uses authentication, Firestore rules, security headers and backend validation. No internet service can guarantee absolute security.

Contact

For project support or data questions, contact the project owner through the email associated with the deployed NEXZO application.
